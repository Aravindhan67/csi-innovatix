Single View Studio: The Figma App Sprint

A focused UI/UX design challenge where participants build functional mobile interfaces within a single screen.

About the Event

"Single View Studio" is a focused 60-minute UI/UX design challenge where participants build a complete, functional mobile app interface within a single screen—no scrolling, tabs, or navigation allowed.

Design Challenge

  • Theme Kick-off: Start with a theme like a weather dashboard, music player, or wellness tracker.
  • Constraint (45 mins): Designers must craft a pixel-perfect, high-density layout in Figma that delivers all core features at a glance.
  • No-Navigation: The strict one-view constraint requires balancing elegance with practicality in minimal space.

Evaluation Criteria

Submissions are judged on visual clarity, information architecture, and usability within the strict constraints, rewarding designs that provide the most value in a single screen.

Event Info

  • Duration 60 Minutes
  • Team Size Individual or 2
  • Category UI/UX Design
