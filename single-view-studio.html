SINGLE VIEW STUDIO

The Figma App Sprint. Design high-density, functional mobile app interfaces in one view.

About the Event

"Single View Studio" is a focused 60-minute UI/UX design challenge where participants build a complete, functional mobile app interface within a single screen—no scrolling, tabs, or navigation allowed.

Design Goals

  • Information Density: Perfect the art of showing more with less space.
  • UX Logic: Ensure a seamless journey without the need for page transitions.
  • Visual Hierarchy: Use color, size, and weight to guide user attention within the view.

Evaluation Criteria

Submissions are judged on visual clarity, information architecture, and usability within the strict constraints, rewarding designs that provide the most value in a single screen.
